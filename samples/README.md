Five portfolio excerpts from the private production repo (`Assets/Scripts` on branch `player-characters`) belong here, flat, under the same filenames. `DraftMath.cs` weights and filters draft offers. `XPManager.cs` handles XP, leveling, and the pause-into-draft handoff. `WeaponBase.cs` is the shared weapon behaviour for the auto-fire loadout. `KillCounter.cs` is a small run metric used by the UI and end-of-run scoring. `ScoreCurve.cs` packs checkpoint score curves for Steam leaderboard rivalry against real players. Each file is an excerpt and may not compile on its own.
